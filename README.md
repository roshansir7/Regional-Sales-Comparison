## Project Summary

This Tableau project provides an interactive comparison of sales performance between two selected regions.

The dashboard was created using the Sample Superstore dataset and helps management compare regional results, identify performance differences and explore the factors contributing to sales outcomes.

## Dashboard Purpose

The main purpose is to answer the following question:

**How does the sales performance of one region compare with another?**

Users can choose a primary region and a secondary region through dashboard parameters. All charts and performance indicators update automatically based on the selected regions.

## Dashboard Measures

The comparison includes:

| Measure                 | Description                               |
| ----------------------- | ----------------------------------------- |
| Total Sales             | Revenue generated in each selected region |
| Average Sales per Order | Average value of customer orders          |
| Number of Customers     | Unique customers purchasing in the region |
| Number of Orders        | Total orders placed                       |
| Number of Products      | Distinct products sold                    |
| First Order Date        | Earliest recorded order                   |
| Category Sales          | Sales performance by product category     |
| Subcategory Sales       | Detailed product-level comparison         |

## Tableau Features

The project demonstrates:

* Region-selection parameters
* Calculated fields
* Dynamic region labels
* Customer and order-level analysis
* Product hierarchies
* Key performance indicators
* Side-by-side regional comparison
* Interactive filters
* Dashboard containers and layout formatting
* Category and subcategory visualisations

## How the Dashboard Works

1. Select a region from the **Primary Region** parameter.
2. Select another region from the **Secondary Region** parameter.
3. Review the key performance indicators for both regions.
4. Compare product-category and subcategory sales.
5. Use the visualisations to identify differences, strengths and weaker areas.

## Business Use

The dashboard can help decision-makers:

* Compare regional sales performance
* Identify high-performing markets
* Find weaker product categories
* Understand regional customer activity
* Support regional marketing strategies
* Allocate resources more effectively
